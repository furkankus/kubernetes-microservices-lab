# Observability Stack

Enterprise-grade observability stack for Kubernetes clusters.

## Components

- Prometheus – Metrics collection
- Grafana – Visualization & dashboards
- Loki – Log aggregation
- Tempo – Distributed tracing

## Features

- Cluster monitoring
- Application metrics
- Centralized logging
- Distributed tracing
- Alerting & notifications
